가상자산이용자보호법 시행이 국내 가상자산시장의 워시 트레이딩에 미친 영향(이준호·최범전, 2026, working paper)의 두 번째 지표는 5분 거래량 분포의 상위 꼬리가 얼마나 두꺼운지를 나타내는 꼬리지수 \(\alpha\) 이다. 워시 트레이딩 프로그램이 일정 범위의 주문을 반복하면 꼬리가 얇아지고, 비정상적으로 큰 거래가 섞이면 꼬리가 두꺼워질 수 있다. 이 글에서는 꼬리지수를 추정하는 Hill 추정량과 꼬리의 시작점 \(x_{\min}\) 을 정하는 Clauset et al. (2009)의 방법을 살펴본다. 예시는 모두 모의 자료이다.

Hill 최우추정량

거래량 \(X\) 가 꼬리 시작점 \(x_{\min}\) 이상에서 파레토 분포 \(P(X>x)=(x/x_{\min})^{-\alpha}\) 를 따른다고 하자. 밀도는 \(f(x)=\alpha x_{\min}^{\alpha}x^{-\alpha-1}\) 이므로 꼬리 관측치 \(x_1,\ldots,x_m\) (\(m=n_{tail}\)) 의 로그우도는

\[ \ell(\alpha)=m\ln\alpha+m\alpha\ln x_{\min}-(\alpha+1)\sum_{i=1}^m\ln x_i \]

이고, \(\partial\ell/\partial\alpha=m/\alpha-\sum_i\ln(x_i/x_{\min})=0\) 을 풀면 Hill (1975) 추정량

\[ \hat\alpha=\frac{m}{\sum_{i=1}^m\ln(x_i/x_{\min})} \tag{1}\]

을 얻는다. \(\ln(X/x_{\min})\) 이 평균 \(1/\alpha\) 인 지수분포를 따르므로 \(\hat\alpha\) 의 근사 표준오차는 \(\hat\alpha/\sqrt m\) 이다. 꼬리 관측치가 100개면 상대오차가 약 10%, 500개면 약 4.5%이다. 논문이 꼬리 관측치를 최소 50개 이상 확보하도록 후보를 제한한 이유이다. 로그–로그 평면에서 경험적 CCDF에 직선을 적합하는 최소자승법은 구간 설정에 따라 결과가 달라지고 편향될 수 있어(Clauset, Shalizi and Newman, 2009), 논문은 최우추정량을 사용한다.

KS 거리에 의한 \(x_{\min}\) 선택

\(x_{\min}\) 을 너무 낮게 잡으면 파레토가 아닌 몸통 부분이 섞여 \(\hat\alpha\) 가 편향되고, 너무 높게 잡으면 꼬리 관측치가 적어 분산이 커진다. Clauset et al. (2009)의 방법은 후보 \(x_{\min}\) 마다 \(\hat\alpha\) 를 추정하고, 꼬리 구간의 경험적 CCDF \(S(x)\) 와 적합된 CCDF \(\hat F(x)=(x/x_{\min})^{-\hat\alpha}\) 사이의 Kolmogorov–Smirnov 거리

\[ D(x_{\min})=\max_{x\ge x_{\min}}\left|S(x)-\hat F(x)\right| \tag{2}\]

가 가장 작은 후보를 고른다. 논문은 각 종목–월 거래량의 50~98% 분위수(1%p 간격)를 후보로 쓴다. 아래 예시는 몸통이 로그정규분포이고 상위 10%가 \(\alpha=1.5\) 인 파레토 꼬리인 자료에 이 절차를 적용한 것이다.

hill <- function(x, xmin) { t <- x[x >= xmin]; length(t) / sum(log(t / xmin)) }
ks_dist <- function(x, xmin, a) {
  t <- sort(x[x >= xmin]); m <- length(t)
  S <- 1 - (seq_len(m) - 1) / m              # 경험적 CCDF  P(X >= t_i)
  max(abs(S - (t / xmin)^(-a)))
}
choose_xmin <- function(x, probs = seq(0.50, 0.98, 0.01), min_tail = 50) {
  cand <- quantile(x, probs, names = FALSE)
  res <- do.call(rbind, lapply(seq_along(cand), function(j) {
    xm <- cand[j]; m <- sum(x >= xm)
    if (m < min_tail) return(NULL)
    a <- hill(x, xm); data.frame(prob = probs[j], xmin = xm, m = m, alpha = a, D = ks_dist(x, xm, a))
  }))
  res[which.min(res$D), ]
}

n <- 8000; x0 <- 100 * exp(1)                # 꼬리 시작점(로그정규 몸통의 약 90% 분위수 근처)
body <- qlnorm(runif(0.9 * n, 0, plnorm(x0, log(40), 0.8)), log(40), 0.8)   # x0 아래로 절단한 로그정규 몸통
x <- c(body, x0 * runif(0.1 * n)^(-1 / 1.5))                                  # x0 이상은 alpha = 1.5 파레토 꼬리
best <- choose_xmin(x)
knitr::kable(transform(best, se = alpha / sqrt(m)), digits = 3, row.names = FALSE,
             col.names = c("분위수", "x_min", "꼬리 관측치 수", "α 추정치", "KS 거리", "표준오차"))

0.9 271.615 800 1.52 0.016 0.054

선택된 분위수는 실제 꼬리 시작점(상위 10%) 근처이고, \(\hat\alpha\) 도 참값 1.5에 가깝다. 다만 이 절차는 추정 절차이지 멱법칙에 대한 검정이 아니다. Clauset et al. (2009)은 이 KS 거리의 부트스트랩 분포로 멱법칙 적합도 p값을 구하는 방법도 제시하였지만, 두꺼운 꼬리 자료에서는 멱법칙과 로그정규분포를 구분하기 어렵다. 논문이 \(\hat\alpha\) 를 엄밀한 멱법칙 검정의 결과가 아니라 “상위 꼬리의 두께를 요약하는 지표”로만 사용하는 이유이다.

정리

  • 꼬리지수는 파레토 우도를 최대화하는 Hill 추정량으로 추정하며, 근사 표준오차는 \(\hat\alpha/\sqrt m\) 이다.
  • 꼬리 시작점은 KS 거리가 가장 작은 후보로 정하되, 꼬리 관측치가 너무 적은 후보는 제외한다.
  • 멱법칙과 로그정규분포는 구분하기 어려우므로, \(\hat\alpha\) 는 검정 결과가 아니라 꼬리 두께의 요약 지표로 쓴다.
